# 旧版与新版功能对照

对照依据：旧版 `gui_main_win_simple.py`、`compiler/*.py`、`log_utils.py`、`server/usage_client.py` 与用户手册。界面布局可以变化，以下业务能力保留。

| 旧版功能 | 新版入口或对应实现 |
| --- | --- |
| 工作区增加、删除、重命名、切换 | 左侧工作区与操作菜单 |
| 根目录联动项目、引擎和 TS 路径 | 路径关联与详细路径 |
| P4 服务器、用户、客户端、强制同步 | P4 配置 |
| P4 客户端检查、已打开文件提示 | 同步流程 |
| 可写文件冲突强制同步 | 同步恢复流程，限定当前项目 |
| 最多三轮自动 resolve | 同步完成后的冲突处理 |
| 等待 UBT、生成工程、UE 编译 | UE 构建流程 |
| TS 定义、组合构建、单独 Watch | 六项任务选择，Watch 独立窗口 |
| 执行前关闭 UE；定时关闭 Rider | 对应手动勾选与固定定时流程 |
| 全选、反选、保存、保存并运行 | 工作区操作 |
| 多个每日触发器、默认 08:00 | 独立计划任务页面，工作区右侧显示摘要 |
| 注册、删除、下次运行状态 | Windows 计划任务区域 |
| DailyBuild 名称、最高权限、错过后补运行 | 原任务兼容与注册设置 |
| 定时固定运行完整流程 | 不受手动勾选项影响 |
| 设置、主题即时切换与单独保存 | 设置，独立 ui-settings.json |
| iWiki 在线帮助 | 帮助文档，保留原链接 |
| 关于、作者和软件说明 | 关于对话框 |
| 程序同级 logs、按日文本日志 | 手动、计划任务与程序日志 |
| 局域网启动/关闭记录 | 原端点、原字段与工具标识 |

新增的离线手册、日志筛选、历史、停止构建、配置备份不会替代上述能力。

保留的保护措施：进程操作限定当前用户；明确失败的构建不会继续执行后续步骤；类型定义失败可恢复备份；P4 参数显式限定目标客户端；不复制旧版吞掉异常后仍报告成功的行为。

仍需真实环境验证：实际 UE/TS 构建、P4 冲突恢复、管理员注册系统任务、公司网络中的文档和统计服务可达性。自动化测试对高风险流程使用替身，不操作真实工作区或计划任务。
