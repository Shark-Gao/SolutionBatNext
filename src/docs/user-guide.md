# SolutionBat Next 使用手册

## 帮助文档

原版在线文档：[MHAutoUpdateCompiler 帮助](https://iwiki.woa.com/p/4018100342?from=iWiki_search)。通过系统默认浏览器打开，访问权限和登录状态由公司文档系统决定。本手册随程序安装，无需联网。

## 工作区管理

左侧工作区分别保存不同分支的项目路径、P4 配置、编译选项和每日触发时间。通过列表旁的加号新建，通过工作区名称旁的操作菜单重命名、复制或删除。删除工作区不会删除项目文件；已注册计划任务的工作区，先删除计划任务再删除或重命名。

## 项目配置

| 配置项 | 含义 |
| --- | --- |
| 项目根目录 | 对应分支的本地根目录，例如 `K:\MHA_Client_main` |
| P4 服务器 / 用户 / 工作区 | Perforce 连接参数与客户端名称 |
| 强制同步 | 对指定客户端执行 `p4 sync -f`，可能覆盖本地可写文件 |
| 项目文件 | `MHAGame\MHMobile.uproject` |
| 引擎目录 | 项目根目录下的 `Engine` |
| TS 项目目录 | `MHAGame\TsProj` |
| UE 命令行程序 | Windows 宿主平台的 UnrealEditor Cmd 程序 |

开启路径关联时，修改根目录或编译配置会更新派生路径。点击“展开路径”可检查详细路径；关闭关联后可手工填写。编译配置支持 Development、DebugGame、Debug、Shipping、Test；构建目标支持 Editor、Game、Client、Server，以实际工程支持的组合为准。

## 手动执行

| 任务 | 执行内容 |
| --- | --- |
| 关闭 UE 进程 | 关闭当前用户的 UE 进程 |
| 更新 P4 全工程 | 检查连接和客户端、查看已打开文件、同步最新代码、处理冲突 |
| 编译 UE 工程 | 等待 UnrealBuildTool，生成工程文件并执行 UE 构建 |
| 生成并构建 TS | 生成 `ue.d.ts`，再启动 TypeScript Watch |
| 生成 TS 定义 | 只生成类型定义 |
| 编译 TS 并启动 Watch | 编译 TypeScript，并持续监听文件变化自动重新编译，不生成类型定义 |

“全选”和“反选”控制手动任务选择。“保存”只保存配置；“保存并运行”先保存，再按顺序执行。TS 组合任务与独立任务重复勾选时不会重复执行同一步骤。

TS Watch 与原版一样在独立窗口运行，关闭该窗口即可停止对应 Watch；主程序的“停止运行”用于停止当前构建流程。生成定义失败时，新版会恢复备份的旧 `ue.d.ts`。

P4 同步与旧版一样会对 `Can't clobber writable file` 报告的可写冲突文件尝试强制同步，并最多三轮尝试 `resolve -am` 自动合并。执行前请提交或备份重要本地更改。未解决的冲突仍需人工处理。

## Windows 计划任务

1. 从工作区右侧“管理计划任务”或左侧“计划任务”进入独立页面，在触发时间表格中添加、编辑每日时间，默认 `08:00`，可设置多个时间点。
2. 以管理员身份运行程序，点击“注册计划任务”。配置会先保存，然后写入 Windows 任务计划程序。
3. 状态行显示任务名称和真实下次运行时间；“执行程序”显示当前任务使用的程序。
4. 修改时间后需再次点击“注册计划任务”，单独保存不会更新系统任务。
5. “删除计划任务”移除系统调度，不删除工作区配置或项目文件。

任务名与原版一致：`DailyBuild_<工作区名称>`。原版任务可以直接识别。重新注册后，同名任务改由新版执行，不会额外创建第二套每日任务。

定时任务固定执行：关闭 Rider 和 UE、更新 P4、编译 UE、生成 TS 定义、启动独立 TS Watch，不受手动任务勾选影响，也不改写手动勾选项。全部步骤成功后，会用本机配置的 Rider（留空时自动查找 2024.3.10）打开当前工作区的 `MHAGame\MHMobile.sln`；失败或停止时不会打开。Rider 的 AI Plan 模式不能通过稳定的启动参数自动切换。

计划任务使用当前用户、最高权限，用户登录时运行；关闭主程序不影响调度。错过时间后由 Windows 在条件允许时补运行。用户未登录、计算机关机或网络不通时，无法保证按时完成。

## 日志与设置

运行日志支持搜索、筛选、复制和导出；“运行记录”按工作区查看历史结果。独立 Watch 的编译输出显示在其自己的窗口中。

拖动日志面板的上边缘可调整高度，双击该边缘恢复默认高度。收起或最大化后还原，会恢复手动设置的高度；高度单独保存在本机，下次打开仍然生效，不会保存未完成的工作区配置。

日志保存在程序所在目录的 `logs` 文件夹。当前便携版的路径为 `K:\SolutionBat\SolutionBatNext\release\logs`，可在“设置”中打开日志目录。手动运行写入 `manual_YYYYMMDD.log`，计划任务写入 `scheduled_task_YYYYMMDD.log`，程序使用记录写入 `gui_main_YYYYMMDD.log`；另存每次执行的 JSONL 日志供软件检索。

配置、界面设置和运行记录索引保存在 exe 同级的 `config` 文件夹，可在“设置”中打开数据目录。配置文件为 `config\config.json`，保存时保留 `config.json.bak`；原版 `config.xml` 不会被改写。升级时会自动复制原用户数据目录中的配置和历史记录，保留工作区编号，原文件留作备份；已有的新配置不会被覆盖。WebView 缓存仍留在用户数据目录。

移动程序时请一并移动 `config` 和 `logs` 文件夹，并更新已有计划任务中的程序和配置目录，可在软件内重新注册。若程序目录不可写，会提示具体错误，不会悄悄改存到其他目录。

浅色、深色和跟随系统主题即时生效并自动保存，不会连带保存未确认的项目表单。界面偏好保存在独立的 `ui-settings.json` 中。

程序打开和关闭时，沿用原版向 `http://10.30.129.88:9876/api/notify` 上报使用记录，包括时间、事件、工具标识、用户、计算机名称、IP、系统和版本信息。发送失败不阻塞构建。

## 常见问题

### 计划任务的执行窗口

计划任务触发时自动打开独立的软件窗口，定位对应工作区，显示完整执行步骤和实时日志，不需要点击“保存并运行”。停止按钮会停止该次任务及其子进程。执行结束后窗口保留结果，不妨碍下一次定时触发；启动阶段的错误也会在窗口显示。旧任务需要更新为带 `--show-gui` 的启动参数，可在软件内重新注册。

P4 更新项目内的程序文件时，如果文件被当前用户打开的同一路径程序占用，软件会请求正常关闭该程序并重试一次。程序拒绝关闭时会中止并提示，不会强制关闭其他工具。

### 注册或删除计划任务失败

先以管理员身份重新打开程序，检查状态行的详细错误；注册失败不会先删除已有任务。

### 找不到 P4 或 TypeScript 编译器

本机需安装 P4 命令行工具与 Node.js，并安装工程自己的 TypeScript 依赖。新版不会在构建时临时下载其他版本的编译器。

### 找不到 UE 命令行程序

检查引擎目录、编译配置和详细程序路径。需要时关闭路径关联并选择正确文件。

### 预演有什么作用

预演只记录将执行的命令，不会同步文件、关闭进程或执行编译，不能代替真实构建验证。

### 在线帮助打不开

检查公司网络和 iWiki 登录状态；本页离线手册不依赖该链接。
